# gopeep skills

Two skills for analyzing and reproducing codebases and websites.

## gopeep-repo

Analyze any software repository and produce structured `gopeep-spec/` files.

Trigger: `/gopeep-repo [path]`, "analyze this repo", "extract architecture", "document this codebase"

## gopeep-web

Analyze a website's HTML/CSS/JS and produce structured `gopeep-spec/` files.

Trigger: `/gopeep-web [source]`, "analyze this website", "reverse engineer this UI", "document this frontend"

---

Use `/gopeep-repo` for local git repos. Use `/gopeep-web` for websites, HTML files, or pasted markup.
